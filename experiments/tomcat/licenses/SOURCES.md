# 来源记录

Tomcat 输入归档由 `NemoYuu/flowlog_benchmark` 提供。数据集卡在版本 `da9e91b3ff75d94604f57ba2b21ef3aa97e241ec` 中标注 Apache-2.0，原始地址记录在 `../inputs/source.json`。

规则为 `flowlog-rs/flowlog-bench` 版本 `ccf29c3ff828b1286be25481e0547b896be8c733` 的 `programs/oracle/souffle/doop.dl`。所取得的上游目录中没有许可文件，规则文件没有许可头。输入数据集的许可说明没有被用于推断规则的许可。

`souffle_phase_driver.cpp` 是本研究中调用 Soufflé 既有嵌入接口的计时入口。Soufflé 本身和系统库由使用者安装。
